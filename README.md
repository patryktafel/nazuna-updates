# Nazuna - aktualizacje

To repozytorium jest publiczne, ale **nie zawiera kodu źródłowego przeglądarki**.
Kod źródłowy Nazuny znajduje się w osobnym, prywatnym repozytorium.

Jedyna rola tego miejsca to hosting wydań (GitHub Releases) używanych przez
wbudowany mechanizm automatycznych aktualizacji (`electron-updater`) w
zainstalowanej wersji Nazuny dla Windows. Każde wydanie zawiera instalator
(`.exe`) oraz plik `latest.yml` z metadanymi, które przeglądarka sama
sprawdza w tle.
